# FitGuard — мониторинг тренировок и аналитика для тренера

FitGuard — информационно-аналитическая система для мониторинга силовых показателей и субъективного самочувствия подопечных. Ученик после тренировки отправляет самочувствие, сон, пульс, вес тела и программу с упражнениями, весами, подходами и повторениями. Система сохраняет данные, сравнивает их с историей и формирует отчёт с динамикой, рисками и рекомендациями для тренера.

## Возможности

- отдельные роли и кабинеты тренера и ученика;
- привязка ученика к тренеру по коду приглашения;
- журнал тренировки с самочувствием, сном, пульсом, весом и заметками;
- повторное использование ранее заполненной программы тренировок;
- автоматический подсчёт тоннажа, подходов и повторений;
- анализ прогресса по каждому упражнению;
- обнаружение недосыпа, жалоб на боль и признаков недовосстановления;
- дашборд тренера с графиками и индикаторами риска;
- антропометрия: рост, вес, замеры и динамика веса;
- адаптивный интерфейс для смартфона и компьютера;
- работа базового анализа без внешнего AI API.

## Тестовые аккаунты

После выполнения `pnpm seed` доступны:

| Роль | Логин | Пароль |
|---|---|---|
| Тренер | `coach` | `coach123` |
| Ученик | `ivan` | `ivan123` |
| Ученица | `maria` | `maria123` |

Для реального VPS эти демонстрационные пароли нужно заменить или удалить.

## Быстрый локальный запуск

Нужны Node.js 22, pnpm 10 и MySQL/MariaDB.

```bash
git clone https://github.com/ВАШ_ЛОГИН/fitguard.git
cd fitguard
corepack enable
corepack prepare pnpm@10.18.0 --activate
pnpm install --frozen-lockfile
cp .env.example .env
# укажите DATABASE_URL и JWT_SECRET в .env
pnpm db:migrate
pnpm seed
pnpm dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Запуск через Docker

```bash
cp .env.example .env
docker compose up -d --build
docker compose exec app npx drizzle-kit migrate
docker compose exec app pnpm seed
```

Приложение будет доступно на [http://localhost:3000](http://localhost:3000). Для постоянного запуска на VPS, домена, HTTPS, Nginx и резервных копий используйте [DEPLOY.md](DEPLOY.md).

## Бесплатный ИИ API — необязательно

FitGuard создаёт базовый аналитический отчёт без внешнего API: считает дельты весов, тоннаж, связь сна и результатов и уровни риска. Для более естественного текстового отчёта можно подключить бесплатный Groq:

```env
AI_PROVIDER=groq
AI_MODEL=llama-3.3-70b-versatile
AI_API_KEY=gsk_ваш_ключ
```

Альтернативы — Google Gemini, OpenRouter или локальная Ollama. Подробности находятся в `.env.example` и [DEPLOY.md](DEPLOY.md).

## Отчёты тренеру

После отправки тренировки отчёт сохраняется в базе данных и становится виден привязанному тренеру в его дашборде. Отдельные email, Telegram или push-уведомления пока не отправляются; для этого потребуется отдельная интеграция с SMTP или Telegram Bot API.

## Технологии

Основной язык — TypeScript. Frontend написан на React 19 и Vite, стилизован Tailwind CSS. Backend работает на Node.js, Express и tRPC. Для базы используется MySQL/MariaDB через Drizzle ORM. Графики построены на Recharts. Docker Compose используется для воспроизводимого запуска приложения и базы на VPS.
